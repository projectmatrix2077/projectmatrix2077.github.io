# Project Matrix 2077

Сайт ролевого киберпанк-сервера Project Matrix 2077 (Conan Exiles, Чикаго 2077): https://projectmatrix2077.github.io

- `index.html`, `app.js` — оформление и движок сайта
- `content/` — тексты страниц и каталоги предметов
- `content/admin-data.js` — настройки, объявление, новости и правки из кабинета администратора
- `art/` — арты и иконки
